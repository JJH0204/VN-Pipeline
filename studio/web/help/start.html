시작하기

VN Studio는 이 Mac 안에서 돌아가는 이미지 생성 엔진(ComfyUI)을 버튼과 화면으로 다루는 로컬 앱입니다. 연애 시뮬레이션·비주얼 노벨에 쓸 캐릭터 시안, 표정 차분이 있는 스탠딩 일러스트(투명 PNG), 이벤트 CG, 배경을 만들 수 있습니다. 참고 이미지나 3D 캐릭터 모델에서 프롬프트(태그)를 뽑아 캐릭터 설정의 출발점으로 삼을 수도 있고, 그 자세를 뼈대 그림(포즈)으로 만들어 생성할 때 같은 자세로 그리게 할 수도 있습니다.

모든 계산은 이 Mac(M4 Pro)에서 하므로 사용료가 없고, 만든 그림이 외부로 전송되지 않습니다. 인터넷은 모델을 내려받을 때만 씁니다. 원격 접속을 켜면 휴대폰이나 다른 PC의 브라우저에서도 이 Mac의 Studio를 열어 생성할 수 있는데, 이때도 그림은 Mac이 그리고 내 Tailscale 기기로만 암호화되어 전달됩니다(아래).

앱 실행

  1. 외장 SSD T7이 연결되어 있는지 확인합니다. 앱, 엔진, 모델이 모두 이 SSD에 들어 있습니다.
  2. /Volumes/T7/VN-Pipeline 폴더의 VN Studio.app을 더블클릭합니다. Dock에 끌어다 두면 다음부터 편하게 열 수 있습니다.
  3. 몇 초 뒤 Chrome 앱 창(Chrome이 없으면 기본 브라우저)에 http://127.0.0.1:8190이 열립니다.
  4. 상단 바의 엔진 상태가 ◌ 시작 중에서 ● 실행 중으로 바뀌면 생성할 수 있습니다. 엔진은 보통 20~60초 안에 켜집니다.

터미널에서는 /Volumes/T7/VN-Pipeline/studio.sh --open을 실행하면 똑같이 동작합니다. 이미 실행 중이면 서버를 새로 띄우지 않고 창만 다시 엽니다.

창을 닫아도 꺼지지 않습니다. 브라우저 창을 닫아도 Studio와 엔진은 뒤에서 계속 실행되고, 진행 중인 작업도 이어집니다. 앱을 다시 더블클릭하면 창만 다시 열립니다. 그래서 긴 작업을 걸어 두고 창을 닫아도 괜찮습니다.

종료

  • 엔진만 끄기: 상단 바의 [중지]를 누릅니다. 엔진은 모델을 올려 둔 동안 메모리를 10GB 안팎 차지하므로, 생성하지 않을 때 꺼 두면 다른 작업이 가벼워집니다. 엔진이 꺼져 있어도 캐릭터·프리셋 편집, 갤러리 보기, 프롬프트 추출과 포즈 만들기는 됩니다.
  • 완전히 종료: 상단 바 오른쪽 끝의 ⋯ 메뉴에서 [VN Studio 종료]를 누릅니다. Studio와, Studio가 띄운 엔진이 함께 종료되고 진행 중인 생성은 중단됩니다. 종료 안내가 나오면 창을 닫으면 됩니다. 엔진을 start.sh나 다른 앱으로 따로 켰다면 그 엔진은 그대로 둡니다. 휴대폰·다른 PC에서 원격으로 접속한 화면에서는 이 항목이 "Mac에서만"으로 비활성화됩니다. 원격에서 끄면 다시 켤 방법이 없기 때문입니다(원격에서 안 되는 것).
  • 터미널에서 종료: 화면이 응답하지 않을 때는 /Volumes/T7/VN-Pipeline/scripts/stop_studio.sh를 실행합니다. 메뉴의 [VN Studio 종료]와 같은 일을 하고, 그래도 남은 프로세스는 직접 끕니다. 따로 켠 엔진까지 끄려면 stop_studio.sh --all을 쓰세요.

같은 ⋯ 메뉴에는 [엔진 로그 보기](엔진이 켜지지 않거나 생성이 실패할 때 원인 확인), 출력·캐릭터·모델·LoRA·설정 폴더 열기, 완료 알림 켜기, [원격 접속 (Tailscale)](휴대폰·다른 PC에서 쓰기 설정)도 있습니다. 폴더 열기는 Mac 화면에 Finder를 여는 기능이라 원격 화면에서는 보이지 않습니다.

SSD를 분리하기 전에는 반드시 완전히 종료하세요. 생성 중에 분리하면 저장 중인 이미지나 설정 파일이 깨질 수 있습니다.

엔진(ComfyUI)과 Studio의 관계

구성 요소주소하는 일

엔진 (ComfyUI)127.0.0.1:8188실제로 이미지를 계산하는 프로그램입니다. Studio가 작업을 보내고, 진행 상황과 실시간 미리보기를 받아 옵니다.

  • 엔진이 꺼져 있으면 화면 위에 "엔진이 꺼져 있습니다" 배너가 뜨고 생성 버튼이 비활성화됩니다. 배너의 [엔진 시작]을 누르세요.
  • 두 서버 모두 이 Mac 안에서만 접속을 받으며(127.0.0.1), 같은 와이파이의 다른 기기에서도 Mac의 IP:8190 같은 주소로는 보이지 않습니다. 다른 기기에서 쓰려면 Tailscale을 거치는 원격 접속을 켜세요. 그때도 Studio는 127.0.0.1에 그대로 있고, Mac의 Tailscale이 내 테일넷의 요청만 Studio로 넘겨 줍니다. 엔진(8188)은 원격으로 열리지 않습니다.

ComfyUI 데스크톱 앱 같은 다른 ComfyUI가 이미 8188 포트를 쓰고 있으면 Studio는 그쪽으로 작업을 보냅니다. 그 엔진은 이 프로젝트의 모델·출력 폴더 설정을 모르기 때문에 모델을 찾지 못하거나 결과가 엉뚱한 폴더에 저장될 수 있습니다. 다른 ComfyUI는 끄고 Studio에서 엔진을 시작하세요.

휴대폰·다른 PC에서 쓰기 (원격 접속)

Tailscale로 이어진 내 기기(iPhone, Windows·Linux PC)의 브라우저에서 https://my-mac.tail1234.ts.net/을 열면 이 Mac의 Studio를 그대로 쓸 수 있습니다. 휴대폰에서는 한 손으로 쓰기 좋은 화면으로 바뀌고, 생성은 Mac이 하므로 휴대폰 성능과 상관없습니다.

  1. 접속할 기기에 Tailscale을 설치하고 Mac과 같은 계정으로 로그인합니다.
  2. Tailscale 관리 화면에서 HTTPS 인증서를 한 번 켭니다.
  3. Mac에서 모델·LoRA › 전역 설정 › 원격 접속 (Tailscale)의 [원격 접속 켜기]를 누르고, 나타난 QR 코드를 휴대폰 카메라로 비춥니다.

Mac이 켜져 있고(잠자기 안 함), T7이 연결되어 있고, VN Studio가 실행 중이어야 합니다. 자동 실행과 잠자기 방지는 아직 들어 있지 않습니다. 단계별 설명, 원격에서 막아 둔 기능, 문제 해결은 원격 접속 가이드를 보세요.

CLI와 함께 쓰기

예전 방식인 python3 vn.py … 명령도 그대로 동작합니다. Studio와 CLI는 같은 설정 파일(config/)과 캐릭터 파일(characters/)을 쓰므로 어느 쪽에서 고쳐도 다른 쪽에 반영됩니다. 다만 CLI로 보낸 작업은 Studio의 작업 탭에 나오지 않고, 결과 이미지만 갤러리에 나타납니다.
