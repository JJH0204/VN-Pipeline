라이선스 주의

NoobAI-XL 모델(noob, noob-hq, noob-eps 프리셋)은 상업적 이용이 금지되어 있으며, 금지 범위에는 모델로 만든 결과물(이미지)도 포함됩니다. 판매할 게임, 후원·광고 수익이 있는 작품에는 이 프리셋으로 만든 그림을 쓰지 마세요.

포즈 따라 그리기의 기본 ControlNet인 NoobAI OpenPose(noob_openpose)에는 라이선스 표기가 없어서, NoobAI-XL과 같은 비상업 조건으로 보는 것이 안전합니다. 판매용 에셋에 포즈를 쓰려면 xinsir ControlNet을 고르세요(보조 모델 정리).

이 문서는 법률 자문이 아니며 일반적인 주의사항을 정리한 것입니다. 라이선스는 바뀔 수 있으므로 쓰기 전에 각 모델의 원본 배포 페이지에서 최신 조건을 직접 확인하세요.

왜 중요한가

체크포인트와 LoRA는 각각 라이선스를 달고 배포됩니다. 어떤 라이선스는 모델 파일뿐 아니라 그 모델로 만든 이미지의 상업적 사용까지 제한합니다. 게임을 판매하는 것은 물론, 무료 게임이라도 후원·광고·유료 DLC가 있으면 상업적 이용으로 볼 수 있습니다.

포즈 감지 코드의 라이선스 표기

이미지(또는 3D 렌더)에서 포즈를 감지할 때 Studio는 엔진 확장 comfyui_controlnet_aux에 들어 있는 코드 파일 두 개(dwpose/dw_onnx/cv_ox_det.py, cv_ox_pose.py)를 불러 쓰고, DWPose 모델로 관절 위치를 찾습니다. 설치된 파일에 적힌 내용은 다음과 같습니다.

  • 확장 전체의 LICENSE.txt: Apache-2.0.
  • 감지 코드가 든 src/custom_controlnet_aux/dwpose/ 폴더의 LICENSE: 카네기멜런대학교(CMU)의 OpenPose 라이선스로, 제목에 "학술·비영리 기관의 비상업 연구용(ACADEMIC OR NON-PROFIT ORGANIZATION NONCOMMERCIAL RESEARCH USE ONLY)"이라고 적혀 있습니다. 같은 폴더의 __init__.py에도 이 전처리기(OpenPose에서 이어받은 코드)는 CMU가 비상업 용도로만 허락했다는 주석이 있습니다.
  • 이 라이선스가 폴더 안의 어느 파일까지 적용되는지는 파일에 따로 적혀 있지 않습니다. Studio가 불러 쓰는 두 파일에는 라이선스 표기가 없습니다.
  • 포즈 맵(뼈대 그림)은 이 확장의 그리기 코드가 아니라 Studio 자체 코드(vnlib/pose.py)가 OpenPose 맵 형식(점·선 색과 순서)에 맞춰 그립니다.

도구의 라이선스가 그 도구로 만든 포즈나 그림에 어떤 영향을 주는지는 이 문서에서 판단할 수 없습니다. 판매할 게임을 낼 계획이라면 출시 전에 위 파일들과 원본 저장소(Fannovel16/comfyui_controlnet_aux, IDEA-Research/DWPose)의 최신 조건을 직접 확인하고, 필요하면 전문가와 상의하세요.

  • 3D 모델의 뼈로 만든 포즈는 이 감지 코드를 거치지 않습니다. 3D 뷰어가 뼈 위치에서 관절 좌표를 계산하고 Studio 자체 코드가 맵을 그립니다. 단, 뼈를 찾지 못해 "렌더에서 감지"로 바뀐 경우(렌더에서 감지)는 감지 코드를 씁니다.
  • 포즈 파일의 .json에는 원본 종류가 기록됩니다. 3D 뼈로 만든 포즈는 "source": "3d", 그림이나 렌더에서 감지한 포즈는 "source": "image"이므로, 나중에 어떤 포즈를 감지로 만들었는지 구별하는 데 참고할 수 있습니다(포즈 파일).
  • 3D 모델과 참고 그림 자체의 이용 약관·저작권도 따로 확인하세요(이용 약관과 저작권).

확인하는 방법

  • Civitai: 모델 페이지의 라이선스·사용 권한 표시를 봅니다. 생성 이미지 판매 가능 여부, 원작자 표기 필요 여부, 유료 생성 서비스 사용 가능 여부 등이 표시되며, 버전마다 다를 수 있습니다. 본문 설명에 추가 조건이 적혀 있는 경우도 많습니다.
  • Hugging Face: 모델 카드 상단의 License 표시와 저장소의 LICENSE 파일을 봅니다.
  • 기록을 남기세요: 사용한 모델·버전·라이선스 페이지를 날짜와 함께 캡처해 프로젝트 폴더(예: docs/licenses/)에 보관하면, 나중에 조건이 바뀌어도 당시 기준을 증명할 수 있습니다.
  • 생성된 PNG에는 사용한 체크포인트와 LoRA 이름이 기록되어 있어, 갤러리의 정보 패널에서 어떤 에셋을 어떤 모델로 만들었는지 확인할 수 있습니다.

게임 개발자를 위한 실무 팁

  • 판매 계획이 있다면 처음부터 정하세요. 상업적 이용이 허용된 모델의 프리셋만 쓰고, 비상업 프리셋은 노트에 "상업 이용 금지"를 적어 두면 실수를 줄일 수 있습니다(NoobAI 프리셋에는 이미 적혀 있습니다).
  • 포즈를 쓴다면 ControlNet도 정하세요. 판매용 에셋은 상업 이용이 허용된 체크포인트에 xinsir ControlNet(강도 1.2 이상)을 쓰세요. 처음 설정된 기본 ControlNet은 NoobAI OpenPose이므로, 모델·LoRA 탭 › 전역 설정에서 미리 바꿔 두면 실수를 줄일 수 있습니다(보조 모델 정리). 포즈는 이용 약관을 확인한 3D 모델의 뼈로 만들면 비상업 표기가 있는 감지 코드를 거치지 않습니다(포즈 감지 코드의 라이선스 표기).
  • 섞지 마세요. 비상업 모델로 만든 그림을 바탕으로 고쳐 그린 에셋도 문제가 될 수 있습니다. 상업용 에셋은 시안 단계부터 허용된 모델로 만드는 것이 안전합니다.
  • 기존 작품의 캐릭터 LoRA(유명 애니·게임 캐릭터)는 모델 라이선스와 별개로 그 캐릭터의 저작권·상표권 문제가 있습니다. 판매용 게임에는 쓰지 마세요.
  • 판매 플랫폼의 AI 정책을 확인하세요. 예를 들어 Steam은 출시 심사 때 AI 생성 콘텐츠 사용 여부를 공개하도록 요구합니다. 다른 스토어도 각자 정책이 있습니다.
  • 사람의 손을 더하세요. AI만으로 만든 이미지는 저작권 보호가 제한적이라는 해석이 국내외에서 일반적입니다. 직접 수정·채색 보정·합성한 작업 기록(레이어가 남은 PSD 등)을 보관하면 품질과 권리 주장 모두에 도움이 됩니다.
  • 에셋 관리표에 "파일 ↔ 모델 ↔ LoRA ↔ 라이선스"를 함께 적어 두면 출시 전 점검이 쉬워집니다.
