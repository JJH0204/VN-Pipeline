프롬프트 작성법

이 앱의 기본 모델들(Illustrious·NoobAI 계열)은 애니메이션 그림 사이트 Danbooru의 태그가 달린 이미지로 학습되었습니다. 그래서 문장보다 쉼표로 구분한 영어 태그를 훨씬 정확하게 알아듣습니다.

1girl, solo, black hair, twintails, maid, holding tray, cafe, smile, upper body

기본 규칙

  • 영어 태그를 쉼표로 구분해 씁니다. 한국어는 이해하지 못합니다.
  • Danbooru 태그 이름의 밑줄(long_hair)은 띄어쓰기(long hair)로 쓰는 것을 권장합니다. 소문자로 씁니다.
  • 태그가 맞는지 모르겠다면 Danbooru(danbooru.donmai.us)에서 검색해 보세요. 그림 수가 많은 태그(대략 1,000장 이상)일수록 모델이 잘 압니다.
  • 생성 탭의 프롬프트 도우미에서 표정·포즈·구도·의상·배경·조명 태그를 클릭해 바로 넣을 수 있습니다.
  • 짧은 영어 구절도 어느 정도 이해하지만(girl holding an umbrella), 같은 뜻의 태그(holding umbrella)가 더 확실합니다.

순서와 구성

앞쪽 태그가 조금 더 강하게 반영되는 경향이 있습니다. 아래 순서로 쓰면 무난합니다.

  1. 인원: 1girl, solo
  2. 외형: 머리 색·길이·모양, 눈 색, 체형, 특징 소품
  3. 의상: 옷 종류와 색
  4. 표정·포즈·구도: smile, standing, upper body, looking at viewer
  5. 배경·조명: classroom, sunlight
  6. 그림체·품질: 품질 태그는 프리셋이 자동으로 붙입니다

앱은 아래 순서로 최종 프롬프트를 조립합니다. 캐릭터를 고르면 1~3번을 캐릭터 정보로 채우므로 여러분은 상황만 쓰면 됩니다.

구분조립 순서
긍정 프롬프트기본 태그 → 외형 → 의상 → 입력한 프롬프트·포즈·장면 → 스타일 → 프리셋 품질 태그
부정 프롬프트프리셋 기본 네거티브 → 캐릭터 네거티브 → 추가 네거티브

예를 들어 haru의 시안(wai 프리셋)은 실제로 이런 프롬프트가 됩니다.

네거티브 프롬프트

네거티브는 "이런 쪽으로는 가지 마"라는 방향을 줍니다. 프리셋에 품질 관련 기본 네거티브(worst quality, bad hands 등)와 nsfw가 이미 들어 있으므로, 추가 네거티브에는 이번 그림에서 자꾸 나오는 것만 짧게 적습니다.

  • 자주 쓰는 예: hat, glasses, multiple girls, text, watermark, cropped
  • 네거티브를 길게 늘어놓으면 그림이 흐려지거나 단조로워질 수 있습니다. 특히 WAI 모델은 짧을수록 좋습니다.
  • "없애기"보다 "원하는 것을 적기"가 더 잘 통합니다. 단발이 자꾸 나오면 네거티브에 short hair를 넣기보다 긍정에 (long hair:1.2)를 쓰는 편이 확실합니다.

캐릭터를 일관되게 유지하는 요령

  • 외형은 캐릭터 칸에 한 번만 적습니다. 매번 손으로 다시 쓰면 조금씩 달라집니다. 캐릭터를 고르면 앱이 같은 태그를 자동으로 넣어 줍니다.
  • 구체적이고 특징적으로 씁니다. cute girl보다 light brown hair, side braid, hair ribbon, amber eyes가 훨씬 일정하게 나옵니다. 머리 장식처럼 눈에 띄는 소품 하나가 "같은 사람"이라는 인상을 크게 좌우합니다.
  • 의상은 색과 부위를 함께 적습니다: navy sailor collar, red neckerchief, navy skirt
  • 색 번짐에 주의합니다. 색 태그가 많으면 다른 부위로 옮겨 가기도 합니다(예: 스카프의 빨간색이 눈 색에 섞임). 중요한 색은 (amber eyes:1.15)처럼 살짝 강조하세요.
  • 충돌하는 태그를 피합니다. 외형에 long hair가 있는데 장면에 short hair를 쓰면 결과가 불안정해집니다.
  • 프리셋과 LoRA를 고정합니다. 모델이 바뀌면 같은 태그라도 얼굴이 달라집니다.
  • 더 강한 일관성이 필요하면 캐릭터 LoRA를 쓰는 방법이 있습니다. 마음에 드는 결과물 20~50장으로 별도 도구(kohya_ss 등)에서 직접 학습할 수 있으며, 만든 LoRA는 캐릭터의 LoRA 칸에 넣으면 됩니다.

길이

태그는 20~40개 정도가 적당합니다. 너무 많으면 각 태그의 힘이 약해지고, 서로 충돌할 가능성도 커집니다. 결과가 마음에 안 들 때 태그를 더 붙이기보다 빼 보는 것도 좋은 방법입니다.
