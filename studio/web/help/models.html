모델(체크포인트)과 프리셋

체크포인트란?

체크포인트(줄여서 모델)는 그림을 그리는 "두뇌"에 해당하는 6~7GB짜리 파일 하나입니다. 그림체, 인체 구조, 어떤 태그가 무엇을 뜻하는지에 대한 지식이 모두 이 안에 들어 있습니다. 모델을 바꾸면 같은 프롬프트와 시드로도 그림체·색감·얼굴이 완전히 달라집니다.

VN Studio에서는 체크포인트 파일을 직접 고르지 않고 프리셋을 고릅니다. 프리셋은 "체크포인트 + 그 모델에 맞는 권장 설정(샘플러, CFG, 스텝, 품질 태그, 기본 네거티브, 기본 LoRA)"을 한데 묶은 것입니다. 같은 체크포인트로 설정만 다른 프리셋을 여러 개 만들 수도 있습니다.

SDXL과 SD1.5는 섞어 쓸 수 없습니다

SDXL과 SD1.5는 내부 구조가 다른 별개의 모델입니다. 그래서:

  • LoRA는 같은 구조의 체크포인트에서만 동작합니다. 이 PC의 add_detail은 SD1.5용이라 SDXL 프리셋에서는 효과가 전혀 없습니다(호환성 배지 ❌).
  • SDXL은 약 100만 화소(1024×1024, 832×1216 등)에서 가장 잘 그리고, SD1.5는 512×512 기준입니다. SD1.5 모델로 832×1216을 그리면 몸이 두 개로 늘어나는 등 쉽게 깨집니다.
  • Civitai 모델 페이지의 Base Model 항목으로 구분합니다. Illustrious, NoobAI, Pony, SDXL 1.0은 모두 SDXL 계열이고, SD 1.5는 SD1.5입니다. Flux, SD 3.5 같은 다른 구조의 모델은 이 앱에서 지원하지 않습니다.
  • 파일 크기로도 짐작할 수 있습니다. SDXL 체크포인트는 보통 6.5~7GB, SD1.5는 2~4GB입니다.
  • 모델·LoRA 탭의 체크포인트 표에 파일에서 직접 읽어 낸 구조(arch)가 표시됩니다.

eps와 v-pred

이미지 생성 모델은 노이즈를 조금씩 걷어 내며 그림을 만듭니다. 이때 모델이 매 단계 무엇을 예측하도록 학습했는지에 따라 두 종류로 나뉩니다.

  • eps(epsilon): "섞여 있는 노이즈"를 예측합니다. 대부분의 모델이 이 방식이며 따로 신경 쓸 것이 없습니다.
  • v-pred(v-prediction): 노이즈와 그림을 섞은 값을 예측합니다. NoobAI-XL Vpred는 이 방식에 ZTSNR(완전한 노이즈에서 출발하는 학습)을 더해 진짜 검정·흰색과 선명한 색, 강한 명암을 표현할 수 있습니다.

v-pred 모델은 생성할 때도 "이 모델은 v-pred"라고 알려 줘야 합니다. 프리셋의 vpred를 켜면 앱이 자동으로 v-pred 샘플링 설정(v_prediction + ZTSNR)과 과포화를 막는 RescaleCFG(0.7)를 넣어 줍니다. 여기에 더해 다음을 지키세요.

  • 샘플러는 euler를 씁니다. NoobAI 공식 권장이며, Euler a(euler_ancestral)나 SDE 계열은 색이 깨지거나 지저분해지기 쉽습니다.
  • CFG는 4~5.5, 스텝은 28~35, 스케줄러는 normal이 무난합니다.
잘못된 설정나타나는 증상
v-pred 모델인데 vpred가 꺼짐회색으로 바랜 색, 대비가 없는 흐릿한 그림, 형체가 불분명한 얼룩
eps 모델인데 vpred가 켜짐지나치게 어둡거나 새까만 그림, 색이 깨진 얼룩
vpred는 켰지만 샘플러가 euler가 아니거나 CFG가 7 이상과포화, 타 버린 색, 지글거리는 노이즈

자동 감지: 앱은 체크포인트 파일의 헤더를 읽어 v-pred 여부를 판단합니다. NoobAI-XL-Vpred-v1.0은 파일 안에 v-pred 표시가 있어 자동으로 감지됩니다. 하지만 v-pred 모델을 섞어 만든 일부 모델은 이 표시가 빠져 있어 eps로 보일 수 있습니다. 파일 이름이나 배포 페이지에 vpred, v-pred, V-Prediction이라고 적혀 있으면 감지 결과와 상관없이 vpred를 켜세요.

모델 찾기와 내려받기

Civitai (civitai.com)

  1. Models 메뉴에서 필터를 겁니다: Model types = Checkpoint, Base model = Illustrious 또는 NoobAI. 이 PC의 LoRA들과 잘 맞고 Danbooru 태그를 잘 이해합니다.
  2. 모델 페이지에서 확인할 것:
    • 오른쪽 정보 영역의 Base Model(위의 구조 구분)
    • 위쪽 버전 탭: 보통 최신 버전을 고릅니다. 버전마다 권장 설정과 파일이 다를 수 있습니다.
    • 파일 형식과 크기: SafeTensor, 6.5GB 안팎(fp16 pruned)
    • 본문 설명의 권장 설정(아래 읽는 법 참고)
    • 라이선스·사용 권한 표시(라이선스 주의 참고)
  3. Download 버튼을 오른쪽 클릭해 링크 주소 복사를 합니다. 주소는 https://civitai.com/api/download/models/123456 같은 형태입니다.
  4. VN Studio의 모델·LoRA 탭 → URL로 다운로드에 붙여 넣고, 폴더를 checkpoints로 고른 뒤 시작합니다. 진행률이 표시되며, 창을 닫아도 다운로드는 계속됩니다.

로그인해야 받을 수 있는 모델이면 오류가 납니다. Civitai 계정 설정(Account Settings)의 API Keys에서 키를 만들어 다운로드 폼의 Civitai 토큰 칸에 넣어 두면, civitai.com 주소에 자동으로 붙여 받습니다. 토큰은 이 PC의 config/settings.json에만 저장되며 다른 사람에게 보여 주면 안 됩니다.

Hugging Face (huggingface.co)

  • 모델 저장소의 Files and versions 탭에서 .safetensors 파일을 찾습니다.
  • 앱으로 받으려면 직접 다운로드 주소가 필요합니다: https://huggingface.co/저장소/resolve/main/파일이름.safetensors. 주소에 /blob/이 들어 있으면 파일이 아니라 웹 페이지이므로 /resolve/로 바꾸세요.
  • 라이선스 동의나 로그인이 필요한 저장소(gated)는 브라우저에서 직접 받은 뒤 아래처럼 폴더에 넣으세요.

직접 넣기

  1. 모델·LoRA 탭의 [모델 폴더 열기]로 /Volumes/T7/VN-Pipeline/models/checkpoints/를 엽니다.
  2. 받은 파일을 넣습니다. 하위 폴더로 정리해도 됩니다(예: illustrious/모델.safetensors).
  3. [목록 새로고침]을 누르면 체크포인트 표에 나타납니다. 엔진은 보통 재시작 없이 새 파일을 인식하지만, 생성할 때 파일을 찾지 못한다는 오류가 나면 엔진을 [재시작]하세요.

.safetensors 파일을 받으세요. .ckpt·.pt 형식은 파일 안에 실행 코드를 숨길 수 있어, 출처가 확실할 때만 써야 합니다. 체크포인트 하나가 6~7GB이므로 T7의 남은 용량도 확인하세요.

실습: aamXLAnimeMix_v10 프리셋 만들기

  1. 모델·LoRA 탭의 체크포인트 표에서 aamXLAnimeMix_v10.safetensors 행을 찾습니다. 사용 중인 프리셋이 없으므로 [프리셋 만들기] 버튼이 보입니다. (프리셋 카드 목록의 [새 프리셋]을 누르고 체크포인트를 골라도 같습니다.)
  2. 앱이 파일을 읽어 SDXL / eps로 감지하고, vpred를 끈 상태로 eps 기본값을 채웁니다: 샘플러 euler_ancestral, 스케줄러 normal, CFG 6, 28스텝, 품질 태그 masterpiece, best quality, amazing quality.
  3. 프리셋 이름(ID)을 aam, 표시 이름을 AAM XL AnimeMix로 정합니다.
  4. Civitai에서 이 모델의 배포 페이지를 찾아 권장 설정을 확인하고, 위의 대응표대로 샘플러·CFG·스텝·품질 태그를 고칩니다. 페이지에 설정이 없으면 기본값 그대로 두고 시작해도 됩니다.
  5. 기본 네거티브는 짧게 시작합니다: worst quality, low quality, lowres, bad anatomy, bad hands, signature, watermark, nsfw
  6. 노트에 "테스트 중, 라이선스 확인 필요"처럼 적고 [저장]합니다.
  7. 비교 테스트: 생성 탭에서 같은 프롬프트, 고정 시드(예: 12345), 빠른 미리보기로 wai와 aam을 한 장씩 뽑아 갤러리에서 번갈아 봅니다. 마음에 안 들면 CFG를 ±1, 샘플러를 하나씩 바꿔 가며 다시 비교합니다. 한 번에 한 가지만 바꿔야 무엇이 효과가 있었는지 알 수 있습니다.
  8. 결과가 좋으면 캐릭터의 모델 프리셋으로 지정하거나, 프리셋 카드에서 [기본으로 지정]을 누릅니다.

aamXLAnimeMix는 파일 이름이나 정보로 계열(Illustrious·NoobAI 등)을 알 수 없는 모델입니다. 이런 모델에서는 LoRA 호환성 배지가 구조(SDXL)만 맞으면 ✅로 표시되므로, Illustrious용 LoRA가 실제로는 약하게 들 수 있습니다. 또 Illustrious·NoobAI 계열이 아닌 모델은 Danbooru 태그를 이해하는 정도가 다를 수 있으니, 결과를 보고 판단하세요.

프리셋 관리 팁

  • 실험할 때는 원본을 고치지 말고 [복제]해서 바꿔 보세요(예: wai → wai-cfg5). 비교가 끝나면 필요 없는 쪽을 지우면 됩니다.
  • 기본 프리셋과 마지막 남은 프리셋은 삭제할 수 없습니다.
  • 캐릭터는 프리셋을 이름으로 기억합니다. 캐릭터가 쓰던 프리셋을 지우면 그 캐릭터는 자동으로 기본 프리셋을 쓰도록 바뀌므로(오류는 나지 않음) 그림체가 달라질 수 있습니다. 지우기 전에 캐릭터 탭에서 모델 프리셋을 원하는 것으로 바꿔 두세요.
  • 프리셋에 연결된 체크포인트 파일의 이름을 바꾸거나 옮기면 그 프리셋은 동작하지 않습니다. 파일을 바꿨다면 프리셋의 체크포인트도 다시 고르세요.
  • 프리셋은 config/presets.json에 저장됩니다. 잘 맞춘 설정은 이 파일을 백업해 두세요.
