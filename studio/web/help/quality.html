품질 설정

생성 화면의 품질 토글(하이레즈·얼굴 보정·손 보정)은 1차로 그린 그림을 여러 단계에 걸쳐 다듬는 과정을 켜고 끕니다. 품질과 시간의 균형을 이해하면 작업 시간을 크게 줄일 수 있습니다.

'강도(denoise)'의 의미

하이레즈, 얼굴·손 보정, 표정 차분에는 모두 강도가 있습니다. 이미 있는 그림을 얼마나 다시 그릴지를 뜻합니다. 0이면 그대로 두고, 1이면 완전히 새로 그립니다.

강도효과
0.2~0.3가벼운 정리. 거의 차이가 없음
0.35~0.45표준. 디테일은 좋아지고 구도·형태는 유지됨
0.5~0.6눈에 띄는 변화. 모양이 바뀌기 시작함
0.7 이상큰 변화. 얼굴이나 자세가 다른 그림처럼 바뀔 수 있음

하이레즈 (Hires fix)

SDXL 모델은 약 100만 화소에서 가장 잘 그리고, 처음부터 크게 그리면 몸이 두 개로 늘어나는 등 구도가 깨집니다. 그래서 적당한 크기로 그린 뒤 → 키우고 → 디테일만 다시 그리는 방식을 씁니다.

  • RealESRGAN 애니 업스케일러로 확대하고, 설정한 배율(기본 1.5배)로 맞춘 뒤, 같은 프롬프트와 시드로 14스텝 동안 강도 0.4로 다시 그립니다.
  • 효과: 눈·머리카락·선이 또렷해지고 옷 주름이 정리되며, 팔다리의 작은 오류도 상당수 고쳐집니다.
  • 끄는 때: 구도만 볼 시안, 프롬프트 테스트.
  • 배율 1.5를 권장합니다. 2.0이면 1664×2432로 더 선명하지만 시간이 두 배 넘게 들고 메모리를 많이 써서 24GB Mac에서는 버거울 수 있습니다.
  • 강도는 0.3~0.45가 안전합니다. 0.55를 넘으면 구도가 바뀌거나 배경에 인물·소품이 새로 생길 수 있습니다.

얼굴 보정

  • 얼굴 감지 모델(face_yolov8m)로 얼굴을 찾아 주변까지 잘라 낸 뒤, 512px로 키워 다시 그리고 경계를 부드럽게 섞어 붙입니다.
  • 얼굴이 작게 그려지는 전신 그림과 와이드 CG에서 효과가 큽니다. 눈이 뭉개지거나 비대칭인 문제를 잘 고칩니다.
  • 상반신 클로즈업처럼 얼굴이 이미 충분히 크면 시간을 아끼기 위해 자동으로 건너뜁니다.
  • 얼굴 보정 강도는 0.3~0.45를 권장합니다. 높일수록 눈이 깔끔해지지만 얼굴 인상과 표정이 조금씩 바뀝니다.
  • 뒷모습, 아주 작은 얼굴, 극단적으로 데포르메된 얼굴은 감지되지 않아 효과가 없을 수 있습니다.

손 보정

  • 손 감지 모델(hand_yolov8s)로 손을 찾아 같은 방식으로 다시 그립니다(기본 강도 0.4).
  • 뭉개진 손가락은 잘 정리하지만, 손가락 개수가 틀리거나 손의 구조 자체가 무너진 경우까지 항상 고치지는 못합니다.
  • 손이 자주 깨지면: 손 보정 강도를 0.45~0.5로 올리기 → detailed_hands_unhinged LoRA를 0.5~0.7로 추가 → 손이 단순한 포즈(arms at sides, arms behind back) 쓰기 → 시드 바꾸기 순으로 시도하세요.
  • 손이 화면에 없는 상반신 그림이라면 손 보정을 꺼서 시간을 아끼세요.

빠른 미리보기

[빠른 미리보기]는 세 토글을 모두 꺼서 832×1216 그대로 1.5~2분 만에 뽑습니다. 시안을 대량으로 뽑거나, 프롬프트·LoRA 강도·새 프리셋을 시험할 때 씁니다.

빠른 미리보기 결과는 눈과 손이 거칠게 보이는 것이 정상입니다. 디테일보다 구도·포즈·분위기만 보고 고르세요. 고른 그림을 갤러리에서 [고품질로 다시] 하면 같은 시드로 품질 단계를 켜서 다시 만들기 때문에, 구도는 그대로 두고 디테일만 좋아집니다.

업스케일 (스프라이트 전용)

스프라이트의 표정 이미지를 애니 업스케일러로 2배(1248×1824 → 2496×3648) 키웁니다. 4K 화면이나 캐릭터를 크게 확대하는 연출이 있을 때만 켜세요. 1920×1080 게임이라면 1824px 높이로도 화면 높이보다 크므로 보통 필요 없습니다. 켜면 표정마다 시간이 더 걸리고 파일이 4배쯤 커집니다.
