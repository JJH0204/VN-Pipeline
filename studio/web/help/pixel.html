도트 (픽셀 아트) 만들기

캐릭터·아이템·배경을 픽셀 아트 리소스로 만듭니다. 그림을 보통처럼 그린 뒤 실제 도트 크기로 줄이고 팔레트 색 수를 제한해, 게임에 바로 넣을 수 있는 실제 픽셀 크기 PNG(예: 64×64)로 저장합니다.

  1. 대상 종류: 캐릭터(전신, 세로) / 아이템·오브젝트(정사각) / 배경·장면(가로, 불투명). 종류에 맞는 태그와 생성 크기가 자동으로 정해집니다.
  2. 만들 대상을 태그로 적습니다. 예: red potion, glass bottle, cork, 1girl, mage, purple robe, staff, forest path, night, fireflies
  3. 도트 크기: 투명 배경(캐릭터·아이템)이면 그림에서 대상 테두리에 맞춰 잘라 낸 뒤 긴 변의 픽셀 수(예: 96이면 서 있는 캐릭터의 키가 96픽셀), 배경·장면이면 결과 가로 픽셀 수입니다. 대상이 그림 속에서 작게 그려져도 결과 크기가 일정하고 빈 여백에 픽셀을 낭비하지 않습니다. 아이템 32~64, 캐릭터 64~128, 배경 128~256이 무난합니다.
  4. 색 수: 8~16색은 레트로(8·16비트), 32~64색은 현대 도트 느낌. 디더링은 그라데이션을 점 무늬로 표현합니다(없음이 가장 깔끔).
  5. 투명 배경: 배경을 지우고 알파를 1비트(완전 투명/불투명)로 잘라 가장자리 반투명 픽셀이 생기지 않게 합니다.
  • 도트로 줄이면 세부가 사라지므로 하이레즈·얼굴/손 보정 없이 1차 생성만 합니다(1장 약 2분).
  • 결과 파일: output/pixel/이름_96px_seed시드_00001_.png(투명) / 이름_가로x세로_seed…(배경). 갤러리·라이트박스는 픽셀이 흐려지지 않게 확대해서 보여 줍니다. 게임 엔진에서도 최근접(Nearest/Point) 필터로 확대하세요.
  • 유리·물처럼 투명한 물체는 배경 제거 때 안쪽에 흰 바탕이 남을 수 있습니다.
  • 도트 전용 LoRA(Illustrious/SDXL용 pixel art LoRA)를 프리셋이나 생성 탭에서 붙이면 원본 그림이 더 도트답게 나와 결과가 좋아집니다.
