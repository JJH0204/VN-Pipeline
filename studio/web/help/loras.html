LoRA 추가·사용법

LoRA란?

LoRA는 체크포인트 위에 덧씌우는 작은 추가 모델(보통 10~300MB)입니다. 모델 전체를 바꾸지 않고 특정 캐릭터, 그림체, 의상, 디테일 같은 특징만 살짝 더해 줍니다. 강도를 조절해 얼마나 세게 적용할지 정할 수 있고, 여러 개를 함께 쓸 수도 있습니다.

그림체·화풍선, 채색, 분위기를 바꿈0.5~0.8있는 경우가 많음

디테일·보정세밀함, 손, 눈 같은 품질 보정0.3~0.6없거나 선택

이 PC의 LoRA (예시)

모델·LoRA 탭의 LoRA 라이브러리는 각 파일의 헤더를 읽어 구조, 학습 베이스 모델, 예측 방식, 트리거 후보를 자동으로 보여 줍니다. 설치된 파일 중 대표적인 것들은 다음과 같습니다.

자동 추출된 트리거 후보를 그대로 믿지 마세요. 후보는 LoRA를 학습할 때 쓰인 이미지에 가장 자주 붙어 있던 태그입니다. 앱이 등급 태그(nsfw, general 등)·품질 태그(absurdres 등)와 드물게 붙은 태그는 걸러 내지만, 남은 후보도 트리거가 아닐 수 있습니다. 예를 들어 detailed_hands_unhinged의 후보 a feminine은 학습 설명문의 조각일 뿐입니다. 배포 페이지의 Trigger Words를 확인하고, 확인한 값은 LoRA 메모에 적어 두세요.

LoRA 찾기와 설치

  1. Civitai에서 Model types = LoRA(LyCORIS·LoCon도 동작합니다)로 필터를 겁니다. Base model은 이 PC의 모델과 맞는 Illustrious 또는 NoobAI를 고르세요. SDXL 1.0이나 Pony용은 ⚠️(효과가 약하거나 그림체가 틀어질 수 있음), SD 1.5용은 ❌(동작 안 함)입니다.
  2. 페이지에서 Base Model, Trigger Words, 본문의 권장 강도, 예시 이미지의 생성 정보(어떤 체크포인트에 어느 강도로 썼는지)를 확인합니다.
  3. Download 링크를 복사해 모델·LoRA 탭의 URL로 다운로드에 붙여 넣고 폴더를 loras로 고릅니다. 또는 [LoRA 폴더 열기]로 /Volumes/T7/VN-Pipeline/models/loras/를 열어 파일을 직접 넣습니다.
  4. [목록 새로고침]을 누르면 LoRA 라이브러리에 나타납니다.
  5. 라이브러리에서 그 LoRA의 메모(트리거, 기본 강도, 설명)를 채워 저장합니다. 기본 강도는 LoRA를 추가할 때 처음 설정되는 값이 되고, 메모는 config/loras.json에 저장됩니다.

/Volumes/T7/ComfyUI/Shared/models/loras/와 엔진 폴더의 models/loras/에 있는 파일도 함께 인식합니다.

강도

  • 0은 꺼짐, 1은 학습한 그대로입니다. 슬라이더는 0~1.5까지 움직입니다. 이 앱은 모델과 텍스트 인코더에 같은 강도를 적용합니다.
  • 배포 페이지의 권장값이 있으면 그 값에서, 없으면 0.7에서 시작해 0.1~0.2씩 조절합니다.
  • 너무 셀 때: 색이 타거나 선이 뭉개지고, 얼굴이 LoRA 학습 이미지처럼 굳어지며, 프롬프트를 무시합니다.
  • 너무 약할 때: 켠 것과 끈 것의 차이가 거의 없습니다.
  • 강도를 비교할 때는 시드를 고정하고 빠른 미리보기로 0.4 / 0.7 / 1.0 세 장을 뽑아 보세요. 같은 시드여야 LoRA의 효과만 비교할 수 있습니다.

트리거 단어

트리거 단어는 LoRA를 학습할 때 설명문에 넣어 둔 키워드입니다. 프롬프트에 넣으면 학습한 특징이 강하게 "켜집니다".

  • 앱이 자동으로 넣어 주지 않습니다. 생성 탭에서 LoRA를 추가한 뒤 트리거 칸의 [넣기] 버튼을 누르거나 직접 적으세요. 캐릭터에 고정할 LoRA라면 트리거를 캐릭터의 외형이나 스타일 칸에 적어 두면 매번 자동으로 들어갑니다. 같은 [넣기] 버튼이 캐릭터 탭에서는 외형 칸(또는 마지막으로 편집한 칸)에, 프리셋 편집에서는 품질 태그 칸에 넣어 줍니다.
  • 그림체·디테일 LoRA는 트리거 없이도 어느 정도 효과가 있지만, 넣으면 더 확실해집니다. 예: AddMicroDetails_Illustrious_v6에는 addmicrodetails.
  • 믿을 수 있는 순서: 배포 페이지의 Trigger Words → 내가 확인해 적은 LoRA 메모 → 자동 추출 후보.

여러 개 함께 쓰기

LoRA는 모두 같은 모델 가중치 위에 겹쳐 더해집니다. 그래서 많이 쌓을수록 서로 간섭합니다.

  • 2~3개 이내로 쓰고, 강도의 합이 대략 1.5~2.0을 넘지 않게 하는 것이 안전합니다.
  • 같은 종류끼리는 충돌합니다. 그림체 LoRA 두 개를 함께 쓰면 하나를 0.3~0.5로 낮추세요.
  • 잘 어울리는 조합: 캐릭터 LoRA + 디테일 LoRA(0.3~0.5), 그림체 LoRA + 손 보정 LoRA.
  • 적용 순서는 프리셋 기본 LoRA → 캐릭터 LoRA → 일회성 LoRA이며, 더하기이므로 순서는 결과에 거의 영향이 없습니다.
  • 같은 LoRA를 두 곳에 넣지 마세요. 예를 들어 프리셋과 캐릭터에 같은 LoRA가 있으면 두 번 적용되어 강도가 두 배가 됩니다.
  • 테스트할 때는 LoRA를 한 번에 하나씩 추가하세요. 그래야 어떤 LoRA가 문제인지 알 수 있습니다.

호환성 배지 ✅ ⚠️ ❌

앱은 LoRA 파일의 헤더(구조, 학습 베이스, 예측 방식)를 각 프리셋의 체크포인트와 비교해 배지를 붙입니다. 배지에 마우스를 올리면 이유가 나옵니다.

배지의미예할 일
✅ 호환구조가 같고 계열에도 문제가 없음. Illustrious와 NoobAI는 같은 뿌리라 서로 호환으로 봅니다.AddMicroDetails + wai그냥 사용
⚠️ 주의구조는 같지만 학습 계열이 다르거나(SDXL 기본 모델용 LoRA를 애니 모델에), v-pred 모델용 LoRA를 eps 모델에 쓰거나, 구조를 판별할 수 없음masterpieces + wai, badhands + wai고정 시드로 켠 것과 끈 것을 비교해 보고 결정
❌ 비호환SD1.5 ↔ SDXL처럼 구조가 다름add_detail + 모든 프리셋쓰지 마세요. 아무 효과가 없고 엔진 로그에 lora key not loaded 경고만 남습니다

✅는 "구조상 연결할 수 있다"는 뜻이지 "그림이 잘 나온다"는 보장은 아닙니다. 특히 계열을 알 수 없는 모델(예: aamXLAnimeMix)에서는 구조만 맞으면 ✅로 표시됩니다.

실습: AddMicroDetails를 WAI에 적용하기

  1. 생성 탭에서 프리셋 wai, 프롬프트 1girl, solo, school uniform, upper body, looking at viewer, smile, classroom, 시드 고정 777, 빠른 미리보기로 LoRA 없이 1장을 뽑습니다.
  2. LoRA 추가에서 AddMicroDetails_Illustrious_v6를 고르고 강도를 0.5로 둡니다. 배지가 ✅인지 확인하고 트리거 칸의 [넣기] 버튼으로 addmicrodetails를 프롬프트에 넣은 뒤 다시 생성합니다.
  3. 갤러리에서 두 장을 번갈아 봅니다. 머리카락 결, 옷감 질감, 눈의 반짝임이 보통 더 세밀해집니다. 지나치면 0.3으로 낮추세요.
  4. 마음에 들면 캐릭터 LoRA로 등록하거나, wai를 복제한 wai-detail 프리셋의 기본 LoRA로 넣어 두세요.
