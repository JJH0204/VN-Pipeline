시안output/haru/concept/haru_wai_seed20261108_00001_.png (캐릭터_프리셋_시드)

  • PNG 파일 안에는 프롬프트·시드·모델·LoRA 같은 생성 정보가 들어 있습니다. 갤러리의 정보 패널이 이 정보를 보여 주며, PNG를 ComfyUI 웹 화면(http://127.0.0.1:8188)에 끌어다 놓으면 만들 때의 워크플로가 그대로 열립니다. 이미지 편집 프로그램에서 다시 저장하면 이 정보가 지워질 수 있으니 원본은 따로 보관하세요.

모델 폴더

  • Studio는 세 곳의 모델 폴더를 함께 인식합니다. 같은 이름의 파일이 여러 곳에 있으면 위쪽이 우선입니다(엔진이 실제로 파일을 찾는 순서와 같습니다).
    1. /Volumes/T7/VN-Pipeline/models/ (새로 받은 파일이 저장되는 곳)
    2. /Volumes/T7/ComfyUI/Installs/ComfyUI/ComfyUI/models/ (엔진 기본 폴더)
    3. /Volumes/T7/ComfyUI/Shared/models/
  • 프리셋은 체크포인트를 파일 이름으로 기억합니다. 프리셋이 쓰는 파일의 이름을 바꾸거나 옮기면 프리셋의 체크포인트도 다시 골라야 합니다.
  • 태거(프롬프트 추출)는 파일이 아니라 폴더 단위로 인식합니다. models/tagger/<태거 이름>/ 폴더 안에 model.onnx와 selected_tags.csv가 둘 다 있어야 목록에 나타나며, 폴더 이름이 곧 태거 이름입니다. 추가 방법은 프롬프트 추출 › 다른 태거 추가를 보세요.
  • ControlNet(포즈 따라 그리기)도 위의 세 곳에서 controlnet/ 폴더를 찾습니다. 앱은 ControlNet을 파일 이름으로 구별해 선 굵기와 권장 강도를 정하므로, 설치된 두 파일의 이름은 바꾸지 마세요(ControlNet 두 종류).

포즈 파일 (input/poses/)

포즈 따라 그리기에서 저장하거나 감지한 포즈는 /Volumes/T7/VN-Pipeline/input/poses/에 쌓입니다. input/은 엔진의 입력 폴더라서, 생성할 때 엔진이 이 폴더에서 포즈 맵을 직접 읽습니다. 포즈 하나는 이름이 같은 파일 여러 개로 이루어집니다.

파일내용없으면
pose_20261109_143015_a1b2.png얇은 선 포즈 맵. 이 파일 이름이 곧 포즈 이름입니다 (만든 날짜_시각_무작위 4자리)포즈가 목록에서 사라집니다
pose_20261109_143015_a1b2.thick.png굵은 선 포즈 맵 (xinsir ControlNet용)xinsir도 얇은 선 맵을 쓰게 되어 큰 동작을 놓치기 쉽습니다
pose_20261109_143015_a1b2.json정보: 원본 종류(3D/이미지), 원본 이름, 각도·프레이밍·클립, 크기, 손 포함 여부, 관절 좌표원본 정보 없이 "업로드" 포즈로 보입니다
pose_20261109_143015_a1b2.src.jpg원본 그림이나 3D 렌더의 축소본(긴 변 1024 이하, 맵과 같은 영역)미리보기와 겹쳐 보기만 안 되고 생성에는 지장 없습니다
  • 파일 이름을 바꾸거나 다른 폴더로 옮기지 마세요. 작업 기록과 갤러리 정보는 포즈를 이름으로 기억하고, 같은 이름의 파일들이 함께 있어야 합니다. 자세한 내용은 포즈 라이브러리를 보세요.
  • 다른 도구에서 만든 OpenPose 뼈대 그림(검은 바탕 PNG)을 이 폴더에 직접 넣어도 "업로드" 포즈로 목록에 나타납니다. 파일 이름은 글자나 숫자로 시작하고 .png로 끝나야 하며, .thick.png로 끝나는 이름은 굵은 선 맵으로 보고 목록에 넣지 않습니다. 이런 그림에는 굵은 선 맵이 따로 없으므로 두 ControlNet 모두 그 그림을 그대로 씁니다.
  • .src.jpg에는 원본 그림의 축소본이 들어 있습니다. 이 폴더를 다른 사람과 공유할 때는 이 점을 기억하세요.

백업

  • 꼭 백업할 것: characters/, config/, 그리고 output/ 중 게임에 쓸 결과물. 용량이 작으니 다른 드라이브나 클라우드에 정기적으로 복사하세요. 자주 쓰는 포즈가 쌓였다면 input/poses/도 함께 백업하세요(포즈 하나에 수십 KB 정도).
  • 모델 파일은 크고 다시 받을 수 있습니다. 기본 세트(WAI, NoobAI Vpred, 업스케일러, 얼굴·손 감지, 배경 제거)는 scripts/download_models.sh로 다시 받을 수 있고, 나머지는 각 배포 페이지에서 받으면 됩니다. 태거는 Hugging Face의 SmilingWolf/wd-eva02-large-tagger-v3에서 model.onnx와 selected_tags.csv를 받아 같은 폴더 이름으로 넣으면 됩니다.
  • ControlNet과 포즈 감지 모델은 download_models.sh에 들어 있지 않습니다. ControlNet은 ControlNet 파일 확인과 다시 받기의 표대로 받아 앱에서 쓰는 이름으로 바꿔 넣고, 포즈 감지 모델은 Hugging Face의 yzd-v/DWPose에서 yolox_l.onnx와 dw-ll_ucoco_384.onnx를 받아 기능별 보조 모델 위치 표의 폴더에 넣으면 됩니다.
  • user/studio/thumbs/는 썸네일 캐시라 언제 지워도 됩니다(필요할 때 다시 만들어짐).

원격 접속 설정이 저장되는 곳

원격 접속의 설정은 두 군데에 나뉘어 저장됩니다. 둘 다 켜져 있어야 다른 기기에서 열립니다.

무엇어디에참고
Studio의 원격 허용, 허용된 로그인, 접속 주소 이름config/settings.json의 remote_enabled, remote_allowed_logins, remote_hosts모델·LoRA › 전역 설정 › 원격 접속 (Tailscale)에서만 바뀝니다. 다른 전역 설정을 저장해도 이 값들은 그대로이며, 직접 고치지 마세요. remote_hosts는 [원격 접속 켜기]를 누를 때 자동으로 채워집니다
Tailscale Serve 설정 (주소 → Studio 연결)이 Mac의 Tailscale 안 (T7이 아님)재시동해도 남습니다. T7을 다른 Mac에 꽂아 쓰면 그 Mac에서 [원격 접속 켜기]를 다시 눌러야 하고, 주소도 그 Mac의 이름으로 바뀝니다
HTTPS 인증서 켜기Tailscale 웹 관리 화면 (테일넷 설정)테일넷마다 한 번만 하면 됩니다
  • Studio 서버 코드에서 원격 접속을 맡는 부분은 studio/remote.py입니다.
  • 원격으로 접속해도 파일의 위치는 같습니다. 원격에서 만든 그림, 저장한 캐릭터·포즈, URL로 받은 모델은 모두 Mac의 T7에 저장되고, 갤러리의 [다운로드]를 눌러야 그 기기로 복사됩니다.

설정 파일을 직접 고칠 때

config/와 characters/의 파일은 JSON 형식입니다. 대부분은 화면에서 고치는 것이 안전합니다. 직접 고친다면 먼저 복사본을 만들어 두세요. 쉼표나 따옴표 하나만 틀려도 파일을 읽지 못해 오류가 납니다.
