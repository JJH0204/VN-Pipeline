시크릿 모드 (테스트·시연용)

테스트하거나 다른 사람에게 시연하면서 만든 그림이 Mac에 계속 쌓이는 것을 막는 모드입니다. 켜 둔 동안 만든 작업은 시크릿 모드를 끄거나 VN Studio를 종료하면 모두 삭제됩니다.

쓰는 법

  1. 상단 바의 시크릿 버튼을 누르고 [시크릿 모드 켜기]를 누릅니다. 휴대폰에서는 상단 ⋯ 메뉴 › [시크릿 모드 켜기]에 있습니다.
  2. 켜져 있는 동안 버튼이 보라색 시크릿 켜짐으로 바뀌고, 상단 바 아래에 보라색 띠가 나옵니다. 평소처럼 생성하면 됩니다.
  3. 그동안 만든 그림은 갤러리·캐릭터·작업 탭에 그대로 보이고, 썸네일 왼쪽 위에 시크릿 표시가 붙습니다.
  4. 끝나면 버튼이나 띠의 [끄고 삭제]를 누릅니다. 지울 작업 수와 그림 수·용량을 보여 주고 한 번 더 묻습니다.

지워지는 것과 남는 것

지워짐남음
시크릿 모드에서 만든 작업 기록(작업 탭)
생성된 그림(output/_secret/)과 썸네일
실시간 미리보기
엔진(ComfyUI)의 실행 기록		 캐릭터 설정, 프리셋, LoRA 메모
저장한 포즈, 다운로드한 모델
시크릿 모드를 켜기 전·끈 뒤에 만든 작업
  • 휴지통을 거치지 않고 바로 지우므로 되돌릴 수 없습니다. 남기고 싶은 그림은 끄기 전에 그림을 크게 보고 [다운로드]로 받아 두세요.
  • 진행 중이거나 대기 중인 시크릿 작업은 끌 때 취소됩니다.
  • 작업 기록 DB는 지운 내용이 파일에 남지 않게 덮어쓰고, 로그에도 시크릿 작업의 프롬프트는 적지 않습니다.
  • 갤러리에서 시크릿 그림을 삭제하면 휴지통으로 가지 않고 바로 지워집니다.

종료·재시작할 때

  • 시크릿 모드를 켠 채 VN Studio를 종료하면 종료하면서 지웁니다. 종료 확인 창에도 안내가 나옵니다.
  • 강제 종료나 전원 끊김으로 지우지 못했으면 다음에 Studio를 시작할 때 지웁니다.
  • 시크릿 모드는 기억되지 않습니다. Studio를 다시 시작하면 꺼진 상태입니다.
  • 원격(휴대폰·다른 PC)에서도 켜고 끌 수 있습니다. 한 기기에서 끄면 다른 기기의 화면에서도 시크릿 그림이 사라집니다.
