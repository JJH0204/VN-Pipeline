용어 사전

도움말과 화면에 나오는 용어를 주제별로 정리했습니다.

기본

엔진 (ComfyUI)
실제로 이미지를 계산하는 프로그램입니다. VN Studio는 엔진에 작업을 보내고 결과를 받아 보여 주는 조작 화면입니다.
체크포인트 (모델)
그림을 그리는 본체가 되는 6~7GB 크기의 파일입니다. 그림체와 지식이 모두 여기에 들어 있습니다. 모델 가이드 참고.
프리셋
체크포인트와 그 모델에 맞는 설정(샘플러·CFG·스텝·품질 태그·네거티브·기본 LoRA)을 묶어 이름을 붙인 것입니다.
LoRA
체크포인트에 특정 캐릭터·그림체·디테일을 덧입히는 작은 추가 모델입니다. LoRA 가이드 참고.
트리거 단어
LoRA가 학습한 특징을 불러내는 키워드입니다. 프롬프트에 직접 넣어야 합니다.
safetensors
모델 파일의 안전한 저장 형식입니다. .ckpt·.pt와 달리 실행 코드를 담을 수 없어 권장됩니다.
Civitai / Hugging Face
모델과 LoRA를 내려받을 수 있는 대표적인 사이트입니다.

프롬프트

프롬프트 (긍정 프롬프트)
그리고 싶은 내용을 적은 글입니다. 이 앱에서는 쉼표로 구분한 영어 태그로 씁니다.
Danbooru 태그
애니 그림 사이트 Danbooru에서 쓰는 분류 태그입니다(long hair, smile 등). Illustrious·NoobAI 계열 모델이 이 태그로 학습되었습니다.
네거티브 (부정 프롬프트)
나오지 않았으면 하는 요소를 적은 글입니다.
품질 태그
masterpiece, best quality처럼 그림의 완성도를 끌어올리는 태그입니다. 프리셋이 자동으로 붙입니다.
가중치
(tag:1.2)처럼 특정 태그의 영향을 키우거나 줄이는 표기입니다.

생성 설정

시드 (seed)
그림의 출발점이 되는 무작위 노이즈의 번호입니다. 조건이 같으면 같은 시드는 같은 그림을 만듭니다.
스텝 (steps)
노이즈를 조금씩 걷어 내는 반복 횟수입니다. 많을수록 오래 걸리고, 일정 수준(약 30)을 넘으면 차이가 거의 없습니다.
CFG
프롬프트를 얼마나 강하게 따를지 정하는 값입니다. 너무 높으면 색이 타고, 너무 낮으면 흐릿해집니다.
샘플러
노이즈를 그림으로 바꿔 가는 계산 방법입니다(euler, euler_ancestral, dpmpp_2m 등).
스케줄러
각 단계에서 노이즈를 얼마나 줄일지 정하는 일정입니다(normal, karras 등).
강도 (denoise)
이미 있는 그림을 얼마나 다시 그릴지를 0~1로 나타낸 값입니다. 하이레즈, 얼굴·손 보정, 표정 차분에 쓰입니다.
VAE
모델 내부의 압축된 그림 데이터를 실제 픽셀로 바꾸는 부분입니다. 이 앱은 체크포인트에 내장된 VAE를 씁니다.

품질 단계

하이레즈 (Hires fix)
작게 그린 그림을 키운 뒤 디테일을 다시 그려 선명하게 만드는 단계입니다.
업스케일러
이미지를 확대하는 전용 모델입니다. 기본값은 애니 그림용 RealESRGAN입니다.
얼굴·손 보정 (디테일러)
얼굴이나 손을 자동으로 찾아 확대해서 다시 그린 뒤 원래 자리에 붙이는 단계입니다.
빠른 미리보기
모든 품질 단계를 끄고 1차 그림만 빠르게 뽑는 방식입니다.

모델 종류

SDXL / SD1.5
이미지 생성 모델의 세대(구조)입니다. 이 앱은 SDXL 기준이며, 구조가 다른 모델과 LoRA는 섞어 쓸 수 없습니다.
Illustrious / NoobAI / Pony
SDXL을 바탕으로 애니 그림을 학습한 대표적인 모델 계열입니다. Illustrious와 NoobAI는 같은 뿌리라 LoRA가 대체로 서로 호환됩니다.
eps / v-pred
모델이 학습한 예측 방식입니다. 대부분은 eps이고, NoobAI-XL Vpred 같은 v-pred 모델은 프리셋의 vpred를 켜고 euler 샘플러를 써야 합니다.
ZTSNR
완전한 노이즈에서 출발하도록 학습하는 방식입니다. v-pred와 함께 쓰여 진짜 검정과 선명한 명암을 표현하게 해 줍니다.
RescaleCFG
v-pred 모델에서 CFG 때문에 색이 과하게 진해지는 것을 막는 보정입니다. vpred 프리셋에 자동으로 들어갑니다.

비주얼 노벨 에셋

시안
캐릭터 디자인을 정하기 위해 여러 장 뽑아 보는 시험 그림입니다.
스탠딩 / 스프라이트
대화 장면에서 캐릭터를 보여 주는 서 있는 전신 그림입니다.
표정 차분
몸은 같고 얼굴 표정만 다른 스탠딩 이미지 세트입니다.
투명 PNG (알파)
배경 부분이 투명한 PNG입니다. 게임 배경 위에 캐릭터를 겹쳐 보여 줄 때 씁니다.
이벤트 CG
중요한 장면에서 화면 전체를 채우는 한 장짜리 일러스트입니다.
큐 (대기열)
엔진이 차례로 처리할 작업 목록입니다. 여러 작업을 걸어 두면 하나씩 순서대로 진행됩니다.

프롬프트 추출 · 포즈

태거 (tagger)
그림을 보고 어떤 Danbooru 태그가 붙을지 확률로 계산하는 이미지 인식 모델입니다. 그림을 그리지 않고 읽기만 하며, 프롬프트 추출 탭에서 씁니다. 설치된 태거는 wd-eva02-large-tagger-v3입니다. 태거란? 참고.
ControlNet
체크포인트 옆에 붙어 "이런 모양으로 그려라"라는 그림 조건을 하나 더 알려 주는 보조 모델입니다. 종류에 따라 자세, 윤곽선, 깊이 등을 따르게 하며, 이 앱은 자세용(OpenPose) ControlNet을 씁니다. 1차 생성에만 적용되고, 쓰면 1차 생성이 약 40% 느려집니다.
OpenPose
사람의 자세를 18개의 점(코·목·어깨·팔꿈치·손목·엉덩이·무릎·발목·눈·귀)과 그 점을 잇는 색깔 선으로 나타내는 방식입니다. 손가락 21점을 더할 수도 있습니다. 선 색으로 오른쪽·왼쪽 부위를 구분합니다.
포즈 맵 (뼈대 그림)
검은 바탕에 OpenPose 점과 선만 그린 그림입니다. OpenPose ControlNet은 이 그림을 보고 인물의 팔다리를 그 위치에 그립니다. 이 앱은 3D 모델의 뼈나 그림에서 감지한 자세로 포즈 맵을 만들어 input/poses/에 저장합니다. 포즈 따라 그리기 참고.
포즈 감지 (DWPose)
그림 속 인물의 관절 위치를 찾아 내는 자세 인식 모델입니다. 이 앱은 [이 그림에서 포즈 감지]와 3D의 "렌더에서 감지"에 이 모델을 쓰며, 엔진 없이 Studio가 직접 처리합니다.
강도 · 적용 구간 (ControlNet)
강도는 포즈를 얼마나 세게 따를지, 적용 구간(끝)은 1차 생성의 처음부터 어디까지 포즈를 적용할지입니다. 하이레즈·보정의 강도(denoise)와는 다른 값입니다. 강도와 적용 구간 참고.
